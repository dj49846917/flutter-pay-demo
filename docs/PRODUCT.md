# 产品范围

## 已实现的可演示能力

| 领域 | 页面/流程 | 当前数据源 |
|---|---|---|
| 账户 | 登录、注册、忘记密码 | 本地校验 |
| 首页 | 总资产、流入流出、待审批、资产、近期交易 | Mock Repository |
| 交易 | 分类筛选、交易列表、详情、处理时间线 | Mock Repository |
| 资金 | 充值二维码、提现、换币、Invoice、法币出金、批量付款 | 演示请求 |
| 企业 | 审批列表、批准/拒绝确认、成员/角色入口 | Mock Repository |
| 增长 | 活动中心、任务进度和奖励 | Mock Repository |
| 用户 | KYB 状态、银行账户、地址簿、安全、设备、通知 | 页面入口 |

## 生产化待办

1. 接入真实身份服务和企业 SSO，并启用 MFA、设备绑定及会话撤销。
2. 对接账本、托管钱包、链节点或托管商、报价、银行出金和 Webhook。
3. 实现 KYC/KYB、制裁名单、KYT/AML、Travel Rule 和地域限制。
4. 由后端执行审批状态机、幂等、双录、日切对账及异常冲正。
5. 补齐推送、深链、埋点、崩溃上报、远程配置和多语言。
6. 完成应用商店主体、金融/虚拟资产许可、隐私政策及地区合规审查。
