# 安全与合规基线

## 客户端

- Access Token 仅存内存，短时 Refresh Token 存 Keychain/Android Keystore；登出与远程撤销时清除。
- 高风险操作要求生物识别或交易级 MFA，生物识别只解锁本地凭据，不能替代服务端授权。
- 禁止记录 Token、密码、身份证件、完整钱包地址、银行账号和交易签名原文。
- 生产环境启用 TLS 1.2+、证书策略、越狱/Root 风险信号、截屏保护和发布混淆；证书固定需设计轮换与应急旁路。
- 客户端不保存托管私钥，不决定可用余额，不绕过审批，不自行确认链上最终性。

## 服务端

- HSM/MPC 管理密钥和签名；热、温、冷钱包分层并限制额度。
- 账本使用双式记账，所有资金指令具备幂等键、不可变审计和 maker-checker 控制。
- 提现执行地址校验、白名单冷静期、KYT、限额、审批和异常速度检测。
- 法币与虚拟资产功能上线前完成目标司法辖区的牌照、KYC/KYB、AML、制裁、Travel Rule、税务及数据驻留评估。

## 发布门禁

SAST、依赖/SBOM、Secret scan、移动端渗透测试、API 权限测试、账务对账测试和灾备演练均通过后，才允许打开真实资金功能开关。
